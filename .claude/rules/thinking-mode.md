# Deep Thinking Mode

**How to invoke adaptive thinking when you need thorough analysis.**

## Trigger Phrases

When you want Claude to give something deep thought, use phrases like:

- "Think deeply about this"
- "Give this some real thought"
- "Ultrathink this"
- "I want thorough analysis"
- "Consider this carefully"

## When It Helps

Deep thinking is valuable for:

| Task | Why |
|------|-----|
| PZ API behavior | Methods may not work as named, B42 changes |
| MP sync issues | Race conditions, state propagation edge cases |
| Cluster algorithm changes | Performance implications, edge cases at boundaries |
| Architecture decisions | Adding features that touch all 3 Lua files |
| Bug investigation | Systematic root cause analysis for in-game issues |

## When NOT Needed

Skip deep thinking for:
- Simple log message changes
- Translation string updates
- Sandbox option additions (mechanical process)
- Single-line bug fixes with obvious cause
